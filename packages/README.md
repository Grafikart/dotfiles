# Paquets explicitement installés

Cet inventaire reprend les paquets conservés dans les listes ci-dessous. Les rôles correspondent aux descriptions fournies par `pacman`.

## Catégories

- [`dev.list`](dev.list) : langages, compilateurs, outils de développement et services utilisés pour développer.
- [`hyprland.list`](hyprland.list) : environnement graphique, session Hyprland/Wayland, audio et intégration du bureau.
- [`misc.list`](misc.list) : système, administration et applications générales.
